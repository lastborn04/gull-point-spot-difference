Gull Point is an illustrated spot-the-difference game set in a fishing harbor. Compare two views of the lighthouse, market quay, and boats. The morning survey has seven differences, and the evening survey has eight.

## Play

- Click or tap a difference in either picture to mark it in both. The counter shows how many remain.
- With a keyboard, Tab to a picture, move the crosshair with the arrow keys, and press Enter or Space to inspect. Hold Shift for finer movement.
- Use up to two hints per survey, or select Replay to start it over. Play untimed by default or enable Timed mode. The clock starts with your first guess or hint, and an incorrect guess costs four seconds. Sound is optional.

## Run locally

With Node.js 22.18 or later, run `node serve.ts` from the repository root and open `http://127.0.0.1:8080` in your browser. You can also serve `game/` with any static HTTP server. The game needs no build step or internet connection.
